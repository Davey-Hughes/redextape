transient unit with a 16 GiB cap so a harness kill cannot take them down. They log into the lane record with an

```
    --setenv=PATH="$PATH" --setenv=CARGO_HOME="$CARGO_HOME" --setenv=RUSTUP_HOME="$RUSTUP_HOME" \

    --setenv=LLVM_SYS_221_PREFIX="$LLVM_SYS_221_PREFIX" --setenv=LLVM_SYS_231_PREFIX="$LLVM_SYS_231_PREFIX" \
    --working-directory=/home/davey/temp/redextape-ir-bumps -- "${@:2}"
}
```
